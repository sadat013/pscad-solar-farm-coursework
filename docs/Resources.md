# Resources for the solar-farm project

The user's reference is [PSCAD Lecture 04: Inverter Based Solar Power Plant Modeling in PSCAD](https://www.youtube.com/watch?v=ZBd5q_PqLRQ&t=340s).

Resources located through [EMT Tools](https://emt-tools.com/):

- [Simple Solar Farm](https://www.pscad.com/knowledge-base/article/521): the closest source match. The video displays the same SimpleSolarFarm and PV_Array_250kW project names, plant-controller arrangement, 100-unit scaling and 250 kW unit rating. The official archive is preserved under source/. Working copies are in model/.
- [Grid-connected Photovoltaic System](https://www.pscad.com/knowledge-base/article/176): an additional PV example for learning the component functions.
- [PSCAD Application Guide and theory workbook](https://www.pscad.com/knowledge-base/article/283): background exercises and theory.
- [Breaker, Faults and Timed Logic Component](https://www.pscad.com/knowledge-base/article/604): useful for understanding the fault tests in the lesson.

The EMT Tools entries above link to PSCAD's own website. The supplied model and technical specification retain their original authorship and licensing.

Setup references:

- [GFortran setup and compatibility](https://www.pscad.com/knowledge-base/article/357)
